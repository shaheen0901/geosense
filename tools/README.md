# Lab tools

Each folder here is a built (static) GeoSENSE Lab tool, opened from the Tools tab.

| Folder | Source repository | How it is updated |
|---|---|---|
| `hrep/` | [shaheen0901/hrep](https://github.com/shaheen0901/hrep) | Automatically, by that repository's GitHub Action, on every push to `main` |

Do not edit these files by hand; change the tool's own repository instead.
